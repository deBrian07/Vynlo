# Vynlo — corrected brand kit

This complete kit uses the chosen **navy tile + mint/teal folded V** logo consistently in the vector exports, PNG icons, wordmarks, and corrected marketing banner.

- `logos/` — editable SVG vector logos and PNG equivalents
- `icons/` — browser extension icons 16, 32, 48, 64, 128, 256, 512px
- `marketing/` — corrected GitHub banner (light and dark), square social art, brand overview, and updated UI screenshot
- `guidelines/` — brand guide and CSS design tokens

Open `marketing/vynlo-brand-overview.png` for a quick preview, then use the standalone assets in production. The SVG logo lockups have outlined typography; no separate font file is required.
