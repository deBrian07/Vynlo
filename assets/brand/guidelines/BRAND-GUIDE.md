# Vynlo Brand Identity — Final selected navy/mint mark

This kit supersedes the earlier violet/lavender V assets. The **only approved icon** is a dark navy rounded-square tile with a folded, two-tone mint/teal V. **Do not use purple V icons in product screenshots or banners.** The extension's existing purple navigation/accent may remain separate from the brand mark.

## Logo usage
- Primary: `logos/vynlo-logo-light-background.svg`
- Dark context: `logos/vynlo-logo-dark-background.svg`
- Primary with tagline: `logos/vynlo-logo-light-background-tagline.svg`
- Symbol: `logos/vynlo-icon.svg` and `logos/vynlo-symbol-only.svg`
- Chrome extension icons: `icons/vynlo-icon-16.png`, `-32.png`, `-48.png`, `-128.png` (additional sizes also included)

## Brand colors
- Navy: `#0F172A` — icon tile / primary wordmark / headings
- Mint: `#2DD4BF` — left V stroke / brand accent
- Teal: `#2C8791` — right V stroke
- Slate: `#94A3B8` — supporting neutral
- Surface: `#F8FAFC` — light-background marketing surfaces
- Existing UI indigo (optional, not a logo color): `#625DF5` — in-product links and active states

## Typography
Inter Display Bold for the name, Inter regular for the tagline/body. SVG wordmarks contain path outlines, so no fonts need to be bundled.

## Do / don't
- Keep the original logo proportions and the right-hand dark-teal stroke.
- Provide enough whitespace around the logo and avoid stretching.
- Use the wordmark without the tagline in compact contexts.
- Never replace the selected mark with a generic white V or purple tile.
- Never use an unreplaced logo in a screenshot mockup.
- In marketing screenshots, use generic example account identifiers; the corrected UI asset uses `hello@example.com`.

## Export
SVG files are resolution-independent. PNG icons are ready for Manifest V3 `icons` and Chrome Web Store uses; use the exact sizes expected by the target application.

`marketing/vynlo-interface-corrected.png` is based on the supplied UI screenshot and has the corrected header icon plus a generic account identifier. `marketing/vynlo-github-banner.png` features this corrected UI screenshot; marketing renders are illustrative and do not claim additional implemented features.
