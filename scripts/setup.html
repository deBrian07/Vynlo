vynlo

Your inbox, with less friction.

Everything is already built. You only need Chrome — no terminal, Vynlo account or API keys.

  1. In Chrome’s address bar, type chrome://extensions and turn on Developer mode.
  2. Click Load unpacked. Select the Vynlo folder next to this guide, inside release.
  3. Open Gmail (or reload it). Use the Vynlo control to open your workspace.

Already installed? Keep using the same installation folder and click Reload on its extension card, then reload Gmail. Moving installations can create a separate local data store.

This is a compatibility preview. Tracking is available only when Gmail’s visible account and conversation identifiers can be verified. Your Vynlo records stay in this browser profile. The ZIP beside this guide is for sharing; you do not need it for these steps.
